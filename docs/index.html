  • Comprehensive testing
  • CI/CD pipeline

💻 Development

Start developing instantly with GitHub Codespaces:

1. Launch Codespace
Click "Launch Codespace" above

2. Build & Run
mvn clean package
docker-compose up

3. Test
mvn verify

🧪 Testing

  • Unit tests with JUnit 5
  • Integration tests with Testcontainers
  • Load testing with JMeter
  • Code coverage with JaCoCo
  • API mocking with WireMock

🏗️ Architecture

  • Java 17 with JAX-RS
  • PostgreSQL database
  • Docker & Docker Compose
  • GitHub Actions CI/CD
  • Swagger/OpenAPI documentation

📊 CI/CD Pipeline

  • Automated testing on every push
  • Docker image building
  • Artifact generation
  • Build verification
